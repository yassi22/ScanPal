# ScanPal

Website security & SEO scanner: enter a URL, get 100+ parallel checks in ~60s
with ranked findings, remediation and exportable reports. Includes GitHub repo
scans, uptime monitoring and an MCP server.

The root [AGENTS.md](AGENTS.md) is the index — read it first. Each layer has
its own AGENTS.md close to the code: [apps/web](apps/web/AGENTS.md),
