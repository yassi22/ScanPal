2. `apps/web/lib/report/data.ts` already receives `(db, scanId, teamId)` and team-scopes the scan query. The implementation joins `teams`, parses branding once and returns it beside `ReportData`.
3. `apps/web/lib/report/pdf.tsx` used `ScanPal Report` and `Generated by ScanPal`; `markdown.ts` used the same two strings. Both now use the branding title, logo/color metadata and hide the footer when requested.
4. Owner auth follows `requireOwner` in `apps/web/lib/authz.ts`. The branding endpoint is `PATCH /api/teams/[teamId]/branding` and calls `assertPlanFeature(..., "white_label")` before persistence.
